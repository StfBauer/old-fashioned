# Edge Case Tests

This directory contains tests for various edge cases and special situations in CSS property ordering.

## Test files

- `edge-cases.test.ts`: Tests for common edge cases in CSS properties
- `advanced-edge-cases.test.ts`: Tests for more complex edge cases
- `scss-edge-cases.test.ts`: Tests for SCSS-specific edge cases
- `real-world-edge-cases.test.ts`: Tests with real-world examples that hit edge cases
- `real-world.test.ts`: Tests with typical real-world CSS examples

These tests ensure that the sorting functionality works correctly even with unusual or complex CSS structures.
