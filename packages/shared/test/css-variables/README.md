# CSS Variables Tests

This directory contains tests specifically for CSS custom properties (variables) handling.

## Test files

- `css-variables-empty-line.test.ts`: Tests for ensuring empty lines after CSS variables
- `css-variables-empty-line-fix.test.ts`: Tests for fixing empty lines after CSS variables
- `css-variables-ordering.test.ts`: Tests for ordering of CSS variables
- `css-variables-property-rules.test.ts`: Tests for CSS variable property rules
- `css-variables-requirement.test.ts`: Tests for CSS variable requirements
- `css-variables-separation.test.ts`: Tests for proper separation of CSS variables from other properties

These tests ensure that CSS variables are handled correctly across all sorting strategies.
