# Changelog

All notable changes to the VS Code Old Fashioned extension will be documented in this file.

## 0.0.1 (Initial Release)

### Features

- Initial release with VS Code extension for CSS property sorting
- Integration with stylelint-oldfashioned-order
- Support for multiple sorting strategies:
  - Alphabetical sorting
  - Concentric sorting
  - Idiomatic sorting
- Configuration options for customizing sorting behavior
